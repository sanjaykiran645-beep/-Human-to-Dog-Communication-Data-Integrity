# Engine B — Blinded Listening Evaluation Protocol

**Status: PENDING.** No independent listening has taken place. No ratings exist in this repository and none may be fabricated.

## Procedure
1. For each category (BARK, GROWL, HOWL, WHINE, YIP, YELP, WHIMPER, CRY, GRUNT, GROAN, PANT) build a set of clips: genuine reference (control), Method A output, Method B output, and (optionally, labelled experimental) Method D output.
2. Rename clips to random IDs; store the key (ID → method, asset_id) separately; shuffle playback order per listener.
3. Use ≥ 5 independent listeners who did not build the system. Use headphones; same playback level.
4. Per clip collect: (a) category chosen from a list incl. "not a dog / unsure", (b) naturalness 1–5, (c) artifact severity 0–3 and type (click/crackle, metallic, robotic, buzz, cut-off), (d) "recognisably a dog?" yes/no.
5. Report per category and per method with the control as the ceiling. Method B passes only if its naturalness and "dog-like" rates are not significantly below Method A and artifact severity ≤ 1.
6. Objective metrics (spectral similarity, MFCC, click counts) are diagnostics only and never evidence of realism.
